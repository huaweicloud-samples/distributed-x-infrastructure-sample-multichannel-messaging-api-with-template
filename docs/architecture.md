# 架构说明

> 多渠道消息 API 华为云架构设计

## 整体架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                              客户端                                      │
│  (Web/Mobile App)                                                        │
└──────────────────────┬──────────────────────────────────────────────────┘
                       │ HTTPS
                       ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                            APIG                                         │
│                     (API Gateway - JWT 认证)                           │
└──────────────────────┬──────────────────────────────────────────────────┘
                       │ HTTP
                       ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         DMS Kafka                                       │
│                    (消息队列 - 异步处理)                                │
│  ┌─────────────────┐                                                   │
│  │   messages      │ ──→ 消息处理器 (CCE Pod)                         │
│  │   (主队列)      │                                                   │
│  └─────────────────┘                                                   │
│  ┌─────────────────┐                                                   │
│  │  messages-dlq   │ ──→ 失败消息存储                                 │
│  │   (死信队列)    │                                                   │
│  └─────────────────┘                                                   │
└──────────────────────┬──────────────────────────────────────────────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │  邮件    │ │   短信   │ │ 模板存储 │
    │  服务    │ │   服务   │ │ GeminiDB │
    └──────────┘ └──────────┘ └──────────┘
```

## 核心组件

### 1. APIG (API 网关)

- **作用**：统一入口，JWT 认证，请求路由
- **特性**：
  - JWT 验证
  - 请求限流
  - HTTPS 加密

### 2. DMS Kafka (消息队列)

- **作用**：异步消息处理，削峰填谷
- **主题**：
  - `messages`：主消息队列
  - `messages-dlq`：死信队列
- **特性**：
  - 高吞吐
  - 持久化
  - 分区有序

### 3. CCE (容器集群)

- **作用**：运行消息处理器
- **部署**：2 副本 Pod
- **扩缩容**：HPA 自动扩缩

### 4. GeminiDB (模板存储)

- **作用**：存储消息模板
- **模式**：DynamoDB 兼容
- **表结构**：
  - `template_name`：模板名称
  - `channel_type`：渠道类型 (EMAIL/SMS)
  - `subject`：邮件主题
  - `body`：消息正文

### 5. CSMS (凭据管理)

- **作用**：安全存储 JWT 密钥
- **加密**：KMS 加密

### 6. SMN (消息通知)

- **作用**：DLQ 告警通知

### 7. CES (监控)

- **作用**：监控告警
- **告警项**：
  - DLQ 消息堆积
  - 容器资源使用

## 数据流

### 发送消息流程

```
1. 客户端 → APIG (带 JWT Token)
2. APIG 验证 JWT Token
3. APIG → DMS Kafka (写入消息)
4. 消息处理器 (CCE) ← DMS Kafka (消费消息)
5. 消息处理器 → GeminiDB (获取模板)
6. 消息处理器 → 邮件/短信服务 (发送消息)
7. 成功/失败 → 客户端
```

### 失败处理流程

```
1. 消息处理失败
2. 消息 → DLQ 主题
3. CES 监控 → DLQ 消息数
4. 超过阈值 → SMN 告警
5. 运维人员处理
```

## 与原 AWS 架构对比

| 组件 | AWS 原方案 | 华为云方案 | 变更说明 |
|------|-----------|-----------|---------|
| API 网关 | API Gateway | APIG | 功能对等 |
| 计算层 | Lambda | CCE | 用户要求替换 |
| 消息队列 | SQS | DMS Kafka | 协议变更 |
| 模板存储 | DynamoDB | GeminiDB | DynamoDB 兼容 |
| 密钥管理 | KMS | KMS | 功能对等 |
| 凭据管理 | Secrets Manager | CSMS | 功能对等 |
| 邮件通知 | SES | SMTP | 无直接对标 |
| 短信通知 | End User Messaging | 短信服务 | 需配置 |
| 主题通知 | SNS | SMN | 功能对等 |
| 监控 | CloudWatch | CES | 功能对等 |

## 架构优势

1. **高可用**：多副本部署，自动故障恢复
2. **可扩展**：Kafka 分区扩展，CCE HPA 扩缩容
3. **异步处理**：消息队列解耦，削峰填谷
4. **安全**：JWT 认证，KMS 加密，CSMS 凭据管理
5. **可观测**：CES 监控，SMN 告警

## 注意事项

1. **邮件服务**：华为云无直接 SES 对标，需使用 SMTP 或第三方服务
2. **容器运维**：CCE 需要 Kubernetes 运维能力
3. **成本**：CCE 按资源计费，与 Lambda 按调用计费模式不同
